# Feature: process-monitor

## Objective

Full-screen terminal process monitor with control (Operating Systems course, URU 2026C, Project 1),
written in Go. Spec: `proyecto1SO.pdf` (15 requirements, summarized below).

## Problem / Why

The course asks for a btop-like monitor that reads process state straight from the OS interface and acts
on processes, so the student can defend how the kernel exposes processes (`/proc`) and how a program
changes them (signals, priority syscalls).

## Hard constraints (from the spec)

- All data comes from `/proc` (Linux). No `gopsutil`, `procfs` or any library returning process lists or CPU %.
- %CPU, totals and summary are computed in our code: process Δ(utime+stime) / system Δ(total jiffies) between two refreshes.
- The program never executes external programs (`ps`, `top`, `kill`...), never reads their output, never uses them to send signals.
- UI libraries are allowed (Bubble Tea + Lipgloss chosen by the owner on 2026-10-14).

## Architecture

```
cmd/procmon/main.go   wiring only
internal/procfs/      READ door: parse /proc into raw structs, no calculations
internal/control/     ACT door: signals (TERM, KILL, STOP, CONT) and priority via syscalls
internal/monitor/     LOGIC: snapshots, %CPU deltas, summary, sort, filter, tree, CPU history
internal/tui/         SCREEN: Bubble Tea model, layout, keys, views
```

Dependency direction: `tui -> monitor -> procfs`, `tui -> control`. The UI never reads `/proc` directly.

## Requirement map

| Req | What | Module |
|-----|------|--------|
| 1 | Table: PID, PPID, user, state, %CPU, %MEM, RSS, threads, priority, CPU time, command | procfs + monitor + tui |
| 2 | Summary: total, running, stopped, zombies, load avg, mem total/used/available | procfs + monitor |
| 3 | Own %CPU by delta, coherent with the system | monitor |
| 4 | Sort by CPU and by memory | monitor |
| 5 | Process tree parent -> child | monitor + tui |
| 6 | Thread view with per-thread state | procfs + tui |
| 7 | CPU history per process | monitor + tui |
| 8 | Highlight zombies (Z) and I/O-blocked (D) | tui |
| 9 | Terminate, force kill (separate confirmation), suspend, resume | control + tui |
| 10 | Show and change priority | control + tui |
| 11 | Full-screen TUI, real size, resize, no flicker, header/table/help line, restore terminal | tui |
| 12 | Refresh interval configurable from the UI | tui |
| 13 | Hot keys: quit, interval, sort, filter, tree, threads, act, priority | tui |
| 14 | Confirmation message naming process and action | tui |
| 15 | Clear message, no crash, when process is gone or permission denied | control + procfs + tui |
